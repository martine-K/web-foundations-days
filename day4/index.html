JavaScript Study Topics

Use these topics to guide your revision.

  • 1. Variables and Data Types

    Learn about let, const, strings, numbers and booleans.

    let student = "Martine";

  • 2. Conditional Statements

    Use if, else and switch to make decisions in programs.

    if (score >= 50) { /* passed */ }

  • 3. Loops

    Repeat tasks using for, while and for...of loops.

    for (let i = 0; i < 3; i++) { }

  • 4. Arrays and Objects

    Store and organize collections of data.

    const topics = ["HTML", "CSS", "JavaScript"];

  • 5. Functions

    Write reusable blocks of code that perform tasks.

    function greet() { return "Hello!"; }

  • 6. DOM and Events

    Interact with webpage elements and respond to user actions.

    button.addEventListener("click", doSomething);
